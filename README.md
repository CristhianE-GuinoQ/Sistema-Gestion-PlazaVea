# 🛒 Sistema de Gestión PlazaVea

Sistema de gestión de ventas desarrollado en Java con interfaz gráfica Swing, integración mediante JDBC y base de datos diseñada con Oracle SQL Developer y Oracle SQL Developer Data Modeler.

## 🚀 Tecnologías utilizadas

- Java
- Java Swing
- JDBC
- Oracle SQL Developer
- Oracle SQL Developer Data Modeler
- SQL

## ✨ Funcionalidades

- Inicio de sesión
- Gestión de clientes
- Gestión de productos
- Gestión de ventas
- Gestión de inventario
- Generación de reportes PDF

## 📂 Estructura del proyecto

- `src/` Código fuente
- `PlazaVea.sql` Base de datos
- `dist/` Ejecutables del proyecto
- `lib/` Librerías utilizadas

## ▶️ Ejecución

1. Importar la base de datos `PlazaVea.sql`.
2. Abrir el proyecto en NetBeans.
3. Ejecutar la clase principal o utilizar `PlazaVea.jar`.
